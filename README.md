\# OptiRoute



A prototype web application designed for interactive warehouse location planning, demand intelligence, and supply chain network optimization.



\## Features

\* \*\*Demand Intelligence:\*\* Visualizes neighborhood-level order demand and volume distribution across urban zones.

\* \*\*Network Configuration \& Topology:\*\* Allows planners to set maximum facilities and optimization heuristics (Cost OPEX, Delivery Speed, Green Routing) to determine optimal hub networks.

\* \*\*What-If Simulator:\*\* Dynamically evaluates variable parameters like demand growth, fuel costs, and hub rent on operational expenditures and capacity limits.

\* \*\*Disruption Stress-Test:\*\* Simulates unexpected hub failures (e.g., power grid failures or strikes) to calculate instant re-routing recovery plans and SLA impacts.



\## AI \& Development

\* \*\*Built with Gemini:\*\* The entire application architecture, logic, user interface, and components were conceptualized, engineered, and developed in collaboration with \*\*Gemini\*\*.

\* \*\*jArvIs Logistics Co-pilot:\*\* An embedded conversational UI powered by browser-integrated AI workflows to act as a real-time assistant for supply chain planning queries.

\* \*\*Speech Integration:\*\* Utilizes browser speech recognition (`SpeechRecognition`) and text-to-speech synthesis for hands-free command inputs and operational briefings.
